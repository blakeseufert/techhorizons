# Bundled fonts

**Archivo** (Omnibus-Type) — the display face in the Tech Horizons design.
Variable font, `wdth` and `wght` axes; the design pins `wdth` to 100.

Bundled rather than packaged because Alpine has no `font-archivo` in any
repo, and the ISO must install with no network. Licensed under the SIL Open
Font License 1.1 — see `OFL-Archivo.txt` — which permits redistribution.

**Inter** is NOT bundled: Alpine ships `font-inter`, so it comes from the
package manager like everything else.
